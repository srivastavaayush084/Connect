Trendtide Connect

Description

AI Powered Influencer Marketing Platform

Features

- Browse and connect with verified creators
- Campaign management and tracking
- Secure authentication and integrations

Installation

1. Clone the repository
2. Install dependencies

```bash
npm install
```

Development

Start the dev server:

```bash
npm run dev
```

Production Build

```bash
npm run build
npm run preview
```

Deployment

Build artifacts are standard Vite outputs. Deploy to any static host or Node server that supports the generated output.

Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS
- TanStack Router / Start

Folder Structure

- src/: application source
  - components/: UI components
  - routes/: route files and app shell
  - lib/: lightweight utilities and services
  - styles.css: global styles
